# PersonaPulse

**Self-serve AI focus groups for every small business in Asia.** Test a product concept on ~100 AI customer personas grounded in real product reviews, then see purchase intent by segment, objections, quotes, AI insights, improved variants, and a back-test proving accuracy on hidden products.

> All results are **AI-simulated customers**. Personas are built from public product review data.

Google Cloud AI Builder Cup 2026 · Retail & Commerce track.

## Repo layout

```
api/      FastAPI (Python 3.11) – Gemini on Vertex AI + BigQuery
web/      Next.js (App Router, TypeScript, Tailwind, Recharts)
scripts/  one-time data jobs (reviews → signals → segments → personas, back-test)
docs/     prompts.md, architecture.md, deploy.md
```

## Run locally

Prereqs: Python 3.11+ (Cloud Run uses 3.11; 3.15 also works locally), Node 22, gcloud CLI.

```bash
gcloud auth application-default login   # ADC; no API keys anywhere
cp .env.example .env                    # fill in GCP_PROJECT etc.
```

API (http://localhost:8080):

```bash
cd api
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
set -a; source ../.env; set +a
uvicorn app.main:app --reload --port 8080
```

Web (http://localhost:3000):

```bash
cd web
cp .env.example .env.local
npm install
npm run dev
```

## Prompts

All Gemini prompts live in [docs/prompts.md](docs/prompts.md) (Prompts 1–8). After editing it, run
`python3 scripts/sync_prompts.py` to copy them verbatim into `api/app/prompts/` (`--check` verifies they match).

## Sample data (until real Gemini runs exist)

`api/app/data/demo.json` and `backtest_sample.json` are **placeholders** generated by
`python3 scripts/make_sample_demo.py`. They power `/demo` and `/backtest` with no Gemini or
BigQuery calls, and the UI labels them as sample data. They get replaced with real results in Phases 4–5.

## Data setup (one-time scripts)

Put the Kaggle "Amazon Sales Dataset" at `data/raw/amazon.csv` (git-ignored), then:

```bash
cd scripts
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python create_tables.py           # dataset + 8 tables (needs billing + ADC)
python load_reviews.py            # split packed reviews, pick 10 hidden back-test products, load reviews_raw
python extract_signals.py         # Prompt 1, ~110 Flash calls, resumable
python build_segments.py          # Prompt 2, one Pro call
python build_personas.py          # Prompt 3, ~100 personas, 30 flagged for live tests
```

Every script takes `--dry-run` to print what it would send without calling Gemini.
Category: electronics accessories (USB cables, earphones, chargers, mice, ...). Reviewer names and
IDs are dropped on load. Hidden back-test products are listed in `scripts/holdout_products.json`
and never reach persona building.
